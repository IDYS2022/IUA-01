# 신호 어휘 — 맥락 카드와 지식을 잇는 유일한 다리

지식 단위의 `신호` 칸에는 여기 있는 말만 쓴다. 맥락 카드의 말을 이 어휘로 바꿔 찾는다.
새 신호는 먼저 여기에 더한다. 같은 뜻의 다른 말은 '같은 말'에 묶는다 (`iua.py find`가 같은 말도 알아듣는다).
갈래는 맥락 카드의 줄(M1~M4 · M6)과 화면 유형, 그리고 사후 진단에서 쓰는 증상이다. 표의 첫 칸이 신호, 셋째 칸이 같은 말이다.
숙련도(초심자 · 숙련자)와 빈도(매일 씀 · 가끔 씀)는 다른 갈래다. 한 단위에 둘 다 붙일 수 있지만, 한쪽으로 다른 쪽을 뜻하지 않는다.

## 사람 — M1

| 신호 | 뜻 | 같은 말 |
|---|---|---|
| 초심자 | 화면의 문법을 아직 외우지 못한 사람 | 처음 쓰는 사람, 신규 사용자 |
| 숙련자 | 손이 기억하는 사람 | 전문가, 파워 유저 |
| 매일 씀 | 거의 매일 같은 일을 한다 | 매일, 자주 씀 |
| 가끔 씀 | 몇 주 · 몇 달에 한 번 | 드물게 씀, 가끔 |
| IT가 낯섦 | 소프트웨어 관례를 모른다 | 비전문가, 현장 담당자 |
| 여러 사람 | 한 화면을 여러 사람이 함께 쓴다 | 협업, 팀 |

## 일의 성격 — M2 · M3

| 신호 | 뜻 | 같은 말 |
|---|---|---|
| 자주 함 | 화면 안에서 반복되는 일 | 반복 |

| 양이 많음 | 항목이 한 화면을 넘는다 | 대량, 많은 데이터 |
| 비교 | 둘 이상을 견준다 | |
| 찾기 | 많은 것 중 원하는 것을 찾는다 | 검색, 탐색 |
| 만들기 | 새것을 만든다 | 생성 |
| 선택 | 정해진 후보 중 고른다 | 고르기, 옵션 |
