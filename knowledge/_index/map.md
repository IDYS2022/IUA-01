# 왜 사슬 — 사실 → 원리 → 상황 → 사례 (렌즈는 가리키는 원리 아래)

아래로 갈수록 구체적이다. 위로 올라가면 "왜"의 답이 나온다.

- `FA-001` 알아보기는 떠올리기보다 쉽다 — 단서가 눈앞에 있으면 기억은 더 빨리, 더 자주 맞게 꺼내진다. (사실)
  - `PR-001` 떠올리게 하지 말고, 보고 고르게 한다 — 사용자가 기억에서 꺼내야 하는 것을 화면이 대신 보여 준다. (원리)
    - `LN-001` 입력 화면을 볼 때 — 입력 화면은 '끝내는 조건 → 틀리기 쉬운 칸 → 저장 뒤' 순서로 본다. (렌즈)
    - `ST-001` 정해진 값은 치게 하지 않고 고르게 한다 — 후보가 정해져 있는 칸에서는 사용자가 값을 외워 치지 않고 보고 고른다. (상황)
    - `TN-001` 보이기 ↔ 줄이기 — 보여 줄수록 떠올릴 일은 줄고 훑을 일은 는다. 어느 쪽이 이기는지는 양과 빈도가 정한다. (긴장)
      - `CS-001` 홈의 최근 작업은 2개가 아니라 한 화면 약 3개 + 넘김 — AI는 줄이기로 2개를 냈고, 사람은 실제 양을 근거로 3개와 넘김을 택했다. (사례)
    - `CS-001` (위에 있음)
- `FA-002` 고를 것이 늘면 고르는 시간이 는다 — 같은 확률의 선택지가 많아질수록 하나를 고르는 데 더 오래 걸린다. (사실)
  - `PR-002` 한 번에 보이는 선택지를 줄인다 — 한 자리에서 고를 것이 적을수록 빨리, 덜 망설이고 고른다. (원리)
    - `LN-001` (위에 있음)
    - `TN-001` (위에 있음)
    - `CS-001` (위에 있음)
